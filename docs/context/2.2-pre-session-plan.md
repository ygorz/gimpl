Phase 1's "no edits" rule flips to "write a file" in Phase 2, so the agent
could carry the wrong rule across the boundary in either direction. The DEMO3
change lands after a DEMO1-only plan is already in context, so the likely
misfires are reverting to DEMO1 only (an outdated rule) or adding DEMO3 to the
spec without updating the map (a stale artifact).
